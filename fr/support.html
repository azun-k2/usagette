Nous contacter

Écrivez à khangazun@gmail.com. Le lien ouvre un message avec un court modèle. Le bouton Écrire au développeur dans Réglages ▸ À propos renseigne pour vous la version de l’app et celle de votre système.

Questions fréquentes

Comment la configurer ?

Ouvrez Usagette, cliquez sur Configurer et, quand on vous le demande, choisissez le dossier .claude de votre dossier personnel (il est masqué ; le panneau s’ouvre directement dessus). Usagette ajoute alors un petit script de ligne d’état. Lancez ou poursuivez une session Claude Code, et les chiffres apparaissent après la première réponse.

La jauge n’affiche aucun chiffre, ou d’anciens chiffres.

Claude Code ne communique vos limites que pendant que vous l’utilisez, uniquement pour les forfaits d’abonnement qui comportent des limites d’usage, et seulement après sa première réponse dans une session. D’ici là, Usagette affiche les derniers chiffres vus, signalés comme anciens, et laisse le compte à rebours tourner. Vérifiez dans Réglages que la ligne d’état est installée.

Cela va-t-il casser ma propre ligne d’état ?

Non. Usagette conserve votre commande de ligne d’état précédente et l’exécute pour vous : ce que vous voyez dans Claude Code ne change pas. Avant la première modification, elle enregistre une sauvegarde de votre settings.json à côté, et Retirer dans Réglages rétablit votre ancienne ligne d’état.

Que modifie Usagette sur mon Mac ?

Seulement deux choses dans le dossier .claude que vous autorisez : ses propres fichiers dans .claude/usagette et l’entrée statusLine de settings.json. Elle n’y lit rien d’autre.

Comment fonctionnent les sons ?

Pour chaque limite, vous choisissez où les sons commencent et l’écart entre eux. Chaque palier est joué une fois par fenêtre, un cran plus fort que le précédent. Si l’usage fait un bond, seul le palier le plus élevé est joué. Les heures calmes, la sourdine et le silence pendant le verrouillage se règlent dans Réglages.

Puis-je utiliser mes propres sons ?

Oui : choisissez le profil Perso et sélectionnez vos fichiers, ou importez un fichier de profil sonore que vous possédez.

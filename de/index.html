Was die App kann

Usagette lebt in der Menüleiste des Mac und zeigt, wie viel Ihrer Claude-Nutzungslimits Sie verbraucht haben: das 5-Stunden-Sitzungslimit, das 7-Tage-Wochenlimit und einen Live-Countdown bis zum jeweiligen Reset. Schalten Sie die gewünschten Teile der Anzeige ein oder aus und öffnen Sie das Fenster für das ganze Bild.

  • Gelesen aus der Statuszeile von Claude Code. Usagette richtet ein kleines Statuszeilen-Skript ein, das die Werte speichert, die Claude Code ohnehin meldet. Ihre eigene Statuszeile funktioniert weiter. Die Werte aktualisieren sich, solange Sie Claude Code nutzen; zwischen den Sitzungen läuft der Countdown einfach weiter.
  • Töne, die mit Ihrem Verbrauch steigen. Legen Sie fest, wo die Töne beginnen und wie groß der Abstand ist. Jede Stufe ist eine Stufe stärker, in fünf Stufen, sodass Sie hören, wie nah Sie dran sind, ohne hinzusehen. Es gibt auch Töne fürs Erreichen eines Limits und für einen Reset.
  • Profile. Normal (sanfte Glocken), Basic (die Standardtöne von macOS), Anime (Funkeln und Sprachfetzen, etwas lustiger) und Eigene (Ihre eigenen Audiodateien). Sie können auch eigene Klangprofil-Dateien importieren.
  • Ruhe, wenn Sie sie brauchen. Ruhezeiten, ein Stummschalter und Stille, solange Ihr Mac gesperrt ist.
  • Kurzbefehle und Start beim Anmelden, wie bei den übrigen Apps der Familie.

Erfordert macOS 14 Sonoma oder neuer und Claude Code. Kommt in den Mac App Store. Nutzungslimits zeigt Claude Code für Abo-Tarife an, die welche haben.

Unexpected lockouts vs Usagette

Monitor your Claude Code session and weekly limits directly from the macOS menu bar.

Sudden Lockouts Mid-coding error: 'Usage limit reached until 3:00 PM' Live countdown in menu bar so you pace complex programming tasks
Status Line Integration Manually checking web dashboards or guessing limits Reads Claude Code status metrics automatically from your local CLI

Datenschutz in einem Absatz

Usagette hat keinen Netzwerkzugriff, keinen Account und kein Tracking, und nichts verlässt Ihren Mac. Die App liest eine einzige Datei, die ihr Statuszeilen-Skript schreibt, im Ordner .claude, dessen Nutzung Sie erlauben. Die vollständige Datenschutzerklärung sagt dasselbe ausführlicher.

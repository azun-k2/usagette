できること

UsagetteはMacのメニューバーに常駐し、Claudeの使用制限をどれだけ使ったかを表示します。5時間セッションの制限、7日間の週間制限、そして各リセットまでのライブカウントダウンです。表示する項目はオン/オフでき、パネルを開けば全体を確認できます。

  • Claude Codeのステータスラインから読み取り。UsagetteはClaude Codeがすでに報告している数値を保存する小さなステータスラインスクリプトを設定します。お使いのステータスラインもそのまま動作します。数値はClaude Codeの使用中に更新され、セッションの合間はカウントダウンがそのまま進みます。
  • 使用量とともに高まる音。音を鳴らし始める位置と、音どうしの間隔を選べます。各段階は5段階で一段ずつ強くなるので、見なくてもどれだけ近づいたかが分かります。上限に達したときとリセットされたときの音もあります。
  • プロファイル。Normal(やわらかなチャイム)、Basic(macOS標準のサウンド)、Anime(きらめきとボイス、少しコミカル)、Custom(お好みのサウンドファイル)。ご自身のサウンドプロファイルファイルを読み込むこともできます。
  • 必要なときは静かに。おやすみ時間、ミュートスイッチ、Macのロック中は無音。
  • ショートカットとログイン時に開く機能も、ファミリーのほかのアプリと同じように使えます。

macOS 14 Sonoma以降とClaude Codeが必要です。Mac App Storeで近日公開。使用制限は、制限のあるサブスクリプションプランでClaude Codeが表示します。

無料のサウンドプロファイル

Usagette 用のサウンドを無料でダウンロードできます。どれも5つのレベルを上がっていき、上限とリセットのための専用サウンドがあります。

  • ダウンロード8-Bit Adventure. コインとパワーアップ、続いてエラー音と体力低下の警報、上限でゲームオーバーの叫び、リセット時にファンファーレ。 サウンド制作：Juhani Junkala、パブリックドメイン（CC0）。
  • ダウンロードArcade Announcer. ゲームのアナウンサー：最初は落ち着いた実況、上がるにつれて「Hurry up!」や「Look out!」、上限で「Game over」。 ボイス制作：Kenney、パブリックドメイン（CC0）。
  • ダウンロードMusic Box. ぜんまい仕掛けの小さなメロディ。上限が近づくにつれて、遅く低く止まっていきます。 Usagette のために作ったオリジナルサウンド。
  • ダウンロードRetro Console. 架空の8ビット機のチップチューン音：パワーアップ、警告サイレン、ゲームオーバーのメロディ。 Usagette のために作ったオリジナルサウンド。
  • ダウンロードSinging Bowls. 最初はやわらかな鉢の音がひとつ、上がるにつれて低く間隔が詰まり、上限でゴングが鳴ります。 Usagette のために作ったオリジナルサウンド。
  • ダウンロードSonar Dive. 潜水艦のソナー：ぽつんと響く探信音から次第に速くなり、上限で潜航警報、浮上中は泡の音。 Usagette のために作ったオリジナルサウンド。

追加するには、Usagette の設定 › サウンドプロファイルを開いて読み込む…を選ぶか、ダウンロードしたファイルをそこにドロップします。ZIPを展開して、プロファイルをダブルクリックしても追加できます。

Unexpected lockouts vs Usagette

Monitor your Claude Code session and weekly limits directly from the macOS menu bar.

Aspect Manual Guesswork / Web Dashboard Usagette
Sudden Lockouts Mid-coding error: 'Usage limit reached until 3:00 PM' Live countdown in menu bar so you pace complex programming tasks
Status Line Integration Manually checking web dashboards or guessing limits Reads Claude Code status metrics automatically from your local CLI
Model Awareness No visibility into how models drain quota Visual feedback highlights token burn across Opus, Sonnet and Haiku
Proactive Alerts Finding out you are locked out only when a prompt fails Gentle native chime or banner alert before your quota runs dry
Privacy & Setup Complex API keys and cloud account sign-ins Zero API keys required; reads local terminal session output safely

プライバシーを1段落で

Usagetteにはネットワークアクセスもアカウントもトラッキングもなく、データがMacの外に出ることはありません。読み取るのは、ステータスラインスクリプトが書き込む1つのファイルだけで、場所は使用を許可した.claudeフォルダ内です。プライバシーポリシーの全文でも、同じ内容をもう少し詳しく説明しています。

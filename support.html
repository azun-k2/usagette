Common questions

How do I set it up?

Open Usagette, press Set up and, when asked, choose the .claude folder in your home folder (it is hidden; the panel opens right on it). Usagette then adds a small status-line script. Start or continue a Claude Code session and the numbers appear after the first reply.

The meter shows no numbers, or old ones.

Claude Code reports your limits only while you use it, only on subscription plans that have usage limits, and only after its first reply in a session. Until then Usagette shows the last numbers it saw, marked as old, and keeps the reset countdown running. Check that the status line is installed in Settings.

Will it break my own status line?

No. Usagette keeps your previous status-line command and runs it for you, so what you see in Claude Code is unchanged. Before the first change it saves a backup of your settings.json next to it, and Remove in Settings puts your previous status line back.

What does Usagette change on my Mac?

Only two things inside the .claude folder you allow: its own files in .claude/usagette, and the statusLine entry in settings.json. It reads nothing else there.

How do the sounds work?

For each limit you pick where the sounds start and the step between them. Each step plays once per window, one level stronger than the last. If usage jumps, only the highest step plays. Quiet hours, mute and silence while locked are in Settings.

Can I use my own sounds?

Yes: choose the Custom profile and pick your own files, or import a sound profile file you have.

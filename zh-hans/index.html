功能简介

Usagette 位于 Mac 菜单栏，显示你已用掉多少 Claude 用量限额：5 小时会话限额、7 天每周限额，以及到每次重置的实时倒计时。可按需开关读数的各个部分，打开面板查看全貌。

  • 从 Claude Code 的状态栏读取。Usagette 会设置一个小型状态栏脚本，保存 Claude Code 本来就会报告的数字。你自己的状态栏照常工作。数字会在你使用 Claude Code 时刷新；两次会话之间，倒计时继续走动。
  • 声音随用量升高。选择提示音从哪里开始以及相邻之间的间隔。每一级都更强，共五级，所以不用看也能听出离限额有多近。到达限额和重置时也有提示音。
  • 配置。普通（轻柔钟声）、基本（macOS 标准声音）、动漫（闪光和语音台词，稍微搞笑一点）和自定（你自己的声音文件）。你还可以导入自己的声音配置文件。
  • 该安静时就安静。安静时段、静音开关，以及 Mac 锁定时保持静默。
  • 快捷指令和登录时打开，与家族中的其他 App 一样。

需要 macOS 14 Sonoma 或更高版本以及 Claude Code。即将登陆 Mac App Store。用量限额由 Claude Code 为设有限额的订阅套餐显示。

免费声音配置

为 Usagette 提供更多声音，可免费下载。每套都会随着五个级别逐步升高，并有各自的上限提示音和重置提示音。

  • 下载8-Bit Adventure. 金币和强化道具，然后是错误提示音和低血量警报，到上限时是游戏结束的惨叫，重置时是一段号角。 声音：Juhani Junkala，公有领域（CC0）。
  • 下载Arcade Announcer. 游戏播报员：起初是平静的播报，随着升高是“Hurry up!”和“Look out!”，到上限时是“Game over”。 语音：Kenney，公有领域（CC0）。
  • 下载Music Box. 上发条的小曲子，随着接近上限而变得更慢、更低沉。 原创声音，专为 Usagette 制作。
  • 下载Retro Console. 来自假想 8 位游戏机的芯片音乐哔声：强化道具、警告警报和游戏结束旋律。 原创声音，专为 Usagette 制作。
  • 下载Singing Bowls. 起初是一声轻柔的钵音，随着升高变得更低、更密集，到上限时是一声锣响。 原创声音，专为 Usagette 制作。
  • 下载Sonar Dive. 潜艇声呐：先是零星的探测声，随后加快，到上限时是下潜警报，上浮时是气泡声。 原创声音，专为 Usagette 制作。

要添加，请在 Usagette 中打开“设置 › 声音配置”并选择“导入…”，或将下载的文件拖放到那里。也可以先解压，再双击该配置。

一段话说明隐私

Usagette 没有网络访问、账户和追踪，没有任何内容会离开你的 Mac。它只读取其状态栏脚本写入的一个文件，位于你允许其使用的 .claude 文件夹中。完整的隐私政策更详细地说明了同样的内容。

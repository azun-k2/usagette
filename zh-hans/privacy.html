简短版本

Usagette 不收集数据、不发送任何内容，也没有网络访问。没有账户、没有分析、没有追踪。

Usagette 读取和写入什么

Usagette 使用你选择的一个文件夹：你个人文件夹中 Claude Code 的 .claude 文件夹。macOS 会请你在普通的“打开”面板中选择一次，Usagette 会记住这个选择。

  • 读取它自己创建的一个文件 .claude/usagette/status.json，其中保存 Claude Code 向状态栏报告的用量数字和重置时间。它不会读取你的对话、项目或文件夹中的其他任何内容。
  • 写入仅限 .claude/usagette 中它自己的钩子文件，以及 .claude/settings.json 中的 statusLine 条目，用于接入状态栏脚本。你之前的状态栏会被保留并照常运行，首次更改前会保存设置文件的备份。

存储了什么，存在哪里

存放在 App 自己位于你 Mac 上的存储空间内：你的设置、它看到的最后一组数字，以及你选择的文件夹。删除 App 即可将它们移除。状态栏文件会保留在你的 .claude 文件夹中，直到你在“设置”中点按移除；它们只包含用量数字。

去向

哪里都不去。Usagette 没有网络访问。它没有网络权限，所以 macOS 本身就不会允许它建立连接。没有服务器，没有任何内容会离开你的 Mac。

独立性

Usagette 为独立制作，与 Anthropic 无关，未获其认可或赞助。Claude 和 Claude Code 是 Anthropic 的商标。

Co robi

Usagette mieszka w pasku menu Maca i pokazuje, ile z limitów użycia Claude już zużyłeś: limit 5-godzinnej sesji, 7-dniowy limit tygodniowy i odliczanie na żywo do każdego resetu. Włączaj lub wyłączaj wybrane części odczytu i otwórz panel, by zobaczyć całość.

  • Odczyt z paska stanu Claude Code. Usagette przygotowuje mały skrypt paska stanu, który zapisuje liczby już raportowane przez Claude Code. Twój własny pasek stanu nadal działa. Liczby odświeżają się, gdy używasz Claude Code; między sesjami odliczanie po prostu biegnie dalej.
  • Dźwięki, które narastają wraz z użyciem. Wybierz, od kiedy grają dźwięki i jaki jest krok między nimi. Każdy krok jest o poziom mocniejszy, w pięciu poziomach, więc słyszysz, jak blisko jesteś, bez patrzenia. Są też dźwięki dla osiągnięcia limitu i dla resetu.
  • Profile. Normal (miękkie dzwoneczki), Basic (standardowe dźwięki macOS), Anime (iskierki i kwestie głosowe, trochę zabawniejsze) i Custom (Twoje pliki dźwiękowe). Możesz też importować własne pliki profili dźwiękowych.
  • Cisza, kiedy trzeba. Godziny ciszy, przełącznik wyciszenia i cisza przy zablokowanym Macu.
  • Skróty i uruchamianie przy logowaniu, tak jak w reszcie rodziny.

Wymaga macOS 14 Sonoma lub nowszego oraz Claude Code. Wkrótce w Mac App Store. Limity użycia pokazuje Claude Code dla planów subskrypcyjnych, które je mają.

Darmowe profile dźwięków

Więcej dźwięków dla Usagette, do pobrania za darmo. Każdy narasta przez pięć poziomów i ma własne dźwięki dla limitu i dla zerowania.

  • Pobierz8-Bit Adventure. Monety i wzmocnienia, potem sygnały błędu i alarmy niskiego zdrowia, okrzyk końca gry przy limicie i fanfary przy zerowaniu. Dźwięki: Juhani Junkala, domena publiczna (CC0).
  • PobierzArcade Announcer. Komentator gry: najpierw spokojne komunikaty, w miarę wspinaczki „Hurry up!” i „Look out!”, przy limicie „Game over”. Głosy: Kenney, domena publiczna (CC0).
  • PobierzMusic Box. Małe melodie na naciąg, które zwalniają i obniżają się, gdy limit się zbliża. Oryginalne dźwięki, stworzone dla Usagette.
  • PobierzRetro Console. Piski chiptune z wyimaginowanej konsoli 8-bitowej: wzmocnienia, syreny ostrzegawcze i melodia końca gry. Oryginalne dźwięki, stworzone dla Usagette.
  • PobierzSinging Bowls. Najpierw jedna łagodna misa, w miarę wspinaczki niższe i gęstsze, a przy limicie gong. Oryginalne dźwięki, stworzone dla Usagette.
  • PobierzSonar Dive. Sonar okrętu podwodnego: pojedyncze pingi, potem szybsze, syrena nurkowania przy limicie i bąbelki podczas wynurzania. Oryginalne dźwięki, stworzone dla Usagette.

Aby dodać profil, otwórz w Usagette Ustawienia › Profile dźwięków i wybierz Importuj… albo upuść tam pobrany plik. Możesz też go rozpakować i dwukrotnie kliknąć profil.

Unexpected lockouts vs Usagette

Monitor your Claude Code session and weekly limits directly from the macOS menu bar.

Aspect Manual Guesswork / Web Dashboard Usagette
Sudden Lockouts Mid-coding error: 'Usage limit reached until 3:00 PM' Live countdown in menu bar so you pace complex programming tasks
Status Line Integration Manually checking web dashboards or guessing limits Reads Claude Code status metrics automatically from your local CLI
Model Awareness No visibility into how models drain quota Visual feedback highlights token burn across Opus, Sonnet and Haiku
Proactive Alerts Finding out you are locked out only when a prompt fails Gentle native chime or banner alert before your quota runs dry
Privacy & Setup Complex API keys and cloud account sign-ins Zero API keys required; reads local terminal session output safely

Prywatność w jednym akapicie

Usagette nie ma dostępu do sieci, konta ani śledzenia, a nic nie opuszcza Twojego Maca. Czyta jeden plik, który zapisuje jej skrypt paska stanu, w folderze .claude, z którego pozwolisz jej korzystać. Pełna polityka prywatności mówi to samo, obszerniej.

ماذا تفعل

تعيش Usagette في شريط قوائم Mac وتعرض مقدار ما استخدمته من حدود استخدام Claude: حد الجلسة (5 ساعات)، والحد الأسبوعي (7 أيام)، وعدًّا تنازليًا مباشرًا لكل إعادة ضبط. شغّل أجزاء العرض التي تريدها أو أوقفها، وافتح اللوحة للصورة الكاملة.

  • تقرأ من سطر الحالة في Claude Code. تُعدّ Usagette سكربتًا صغيرًا لسطر الحالة يحفظ الأرقام التي يعرضها Claude Code أصلًا. يواصل سطر الحالة الخاص بك العمل. تتجدّد الأرقام أثناء استخدامك Claude Code، وبين الجلسات يستمر العدّ التنازلي ببساطة.
  • أصوات ترتفع مع استخدامك. اختر أين تبدأ الأصوات والفاصل بينها. كل خطوة أقوى بدرجة، في خمسة مستويات، فتعرف مدى قربك من الحد دون أن تنظر. وهناك أيضًا أصوات لبلوغ الحد ولإعادة الضبط.
  • ملفات التعريف. عادي (أجراس ناعمة)، أساسي (أصوات macOS القياسية)، أنمي (بريق وعبارات صوتية، أكثر طرافة قليلًا)، ومخصّص (ملفات الصوت الخاصة بك). ويمكنك أيضًا استيراد ملفات تعريف الصوت الخاصة بك.
  • الهدوء عند الحاجة. ساعات هدوء، ومفتاح كتم، وصمت أثناء قفل جهاز Mac.
  • الاختصارات والتشغيل عند تسجيل الدخول، مثل بقية تطبيقات العائلة.

يتطلب macOS 14 Sonoma أو أحدث وClaude Code. قريبًا على Mac App Store. يعرض Claude Code حدود الاستخدام لباقات الاشتراك التي تتضمنها.

ملفات أصوات مجانية

المزيد من الأصوات لـ Usagette، للتنزيل مجانًا. يرتقي كل ملف عبر المستويات الخمسة وله أصواته الخاصة عند بلوغ الحد وعند إعادة الضبط.

  • تنزيل8-Bit Adventure. عملات معدنية ومعزّزات، ثم صفّارات الخطأ وإنذارات انخفاض الطاقة، وصرخة نهاية اللعبة عند بلوغ الحد، وفاصل احتفالي عند إعادة الضبط. أصوات من تأليف Juhani Junkala، ملكية عامة (CC0).
  • تنزيلArcade Announcer. مذيع ألعاب: تنبيهات هادئة في البداية، ثم “Hurry up!” و“Look out!” كلما ارتفعتَ، و“Game over” عند بلوغ الحد. أصوات من Kenney، ملكية عامة (CC0).
  • تنزيلMusic Box. ألحان صغيرة تعمل بالتعبئة تتباطأ وتنخفض نغمتها كلما اقترب الحد. أصوات أصلية، صُنعت لـ Usagette.
  • تنزيلRetro Console. صفّارات موسيقى الشيبتيون من جهاز ألعاب خيالي بتقنية 8 بت: معزّزات وصفّارات إنذار ولحن نهاية اللعبة. أصوات أصلية، صُنعت لـ Usagette.
  • تنزيلSinging Bowls. وعاء واحد هادئ في البداية، ثم أخفض وأكثر تقاربًا كلما ارتفعتَ، وقرع صنج عند بلوغ الحد. أصوات أصلية، صُنعت لـ Usagette.
  • تنزيلSonar Dive. سونار غواصة: نبضات منفردة، ثم أسرع، وصفارة غوص عند بلوغ الحد وفقاعات أثناء الصعود. أصوات أصلية، صُنعت لـ Usagette.

Unexpected lockouts vs Usagette

Monitor your Claude Code session and weekly limits directly from the macOS menu bar.

Aspect Manual Guesswork / Web Dashboard Usagette
Sudden Lockouts Mid-coding error: 'Usage limit reached until 3:00 PM' Live countdown in menu bar so you pace complex programming tasks
Status Line Integration Manually checking web dashboards or guessing limits Reads Claude Code status metrics automatically from your local CLI
Model Awareness No visibility into how models drain quota Visual feedback highlights token burn across Opus, Sonnet and Haiku
Proactive Alerts Finding out you are locked out only when a prompt fails Gentle native chime or banner alert before your quota runs dry
Privacy & Setup Complex API keys and cloud account sign-ins Zero API keys required; reads local terminal session output safely

الخصوصية في فقرة واحدة

لا تملك Usagette وصولًا إلى الشبكة ولا حسابًا ولا تتبّعًا، ولا شيء يغادر جهاز Mac الخاص بك. تقرأ ملفًا واحدًا يكتبه سكربت سطر الحالة الخاص بها، في المجلد .claude الذي تسمح لها باستخدامه. وتقول سياسة الخصوصية الكاملة الشيء نفسه بتفصيل أكبر.

常見問題

如何設定？

打開 Usagette，按一下設定，在系統提示時選擇你個人檔案夾中的 .claude 檔案夾（它是隱藏的；面板會直接開啟到那裡）。然後 Usagette 會新增一個小型狀態列腳本。開始或繼續一個 Claude Code 工作階段，首次回覆後數字就會出現。

表上沒有數字，或者數字是舊的。

Claude Code 只在你使用它時、只針對設有用量限額的訂閱方案、且只在工作階段中的首次回覆之後才會回報限額。在此之前，Usagette 會顯示它看到的最後一組數字並標為舊資料，同時讓重置倒數繼續走動。請在「設定」中檢查狀態列是否已安裝。

它會弄壞我自己的狀態列嗎？

不會。Usagette 會保留你之前的狀態列指令並替你執行，所以你在 Claude Code 中看到的內容不變。首次更改前，它會在旁邊儲存一份 settings.json 的備份，而「設定」中的移除會恢復你之前的狀態列。

Usagette 會更改我 Mac 上的什麼？

只在你允許的 .claude 檔案夾內更改兩處：.claude/usagette 中它自己的檔案，以及 settings.json 中的 statusLine 項目。它不會讀取那裡的其他任何內容。

聲音是怎麼運作的？

對每個限額，你選擇提示音從哪裡開始以及相鄰之間的間隔。每一級在每個視窗內播放一次，比上一級強一級。如果用量暴增，只播放最高的那一級。安靜時段、靜音和鎖定時靜默都在「設定」中。

我可以使用自己的聲音嗎？

可以：選擇「自訂」設定檔並選取你自己的檔案，或匯入你已有的聲音設定檔。

簡短版本

Usagette 不收集資料、不傳送任何內容，也沒有網路存取。沒有帳號、沒有分析、沒有追蹤。

Usagette 讀取和寫入什麼

Usagette 使用你選擇的一個檔案夾：你個人檔案夾中 Claude Code 的 .claude 檔案夾。macOS 會請你在一般的「打開」面板中選擇一次，Usagette 會記住這個選擇。

  • 讀取它自己建立的一個檔案 .claude/usagette/status.json，其中儲存 Claude Code 向狀態列回報的用量數字和重置時間。它不會讀取你的對話、專案或檔案夾中的其他任何內容。
  • 寫入僅限 .claude/usagette 中它自己的掛勾檔案，以及 .claude/settings.json 中的 statusLine 項目，用於接入狀態列腳本。你之前的狀態列會被保留並照常執行，首次更改前會儲存設定檔的備份。

儲存了什麼，存在哪裡

存放在 App 自己位於你 Mac 上的儲存空間內：你的設定、它看到的最後一組數字，以及你選擇的檔案夾。刪除 App 即可將它們移除。狀態列檔案會保留在你的 .claude 檔案夾中，直到你在「設定」中按一下移除；它們只包含用量數字。

去向

哪裡都不去。Usagette 沒有網路存取。它沒有網路權限，所以 macOS 本身就不會允許它建立連線。沒有伺服器，沒有任何內容會離開你的 Mac。

獨立性

Usagette 為獨立製作，與 Anthropic 無關，未獲其認可或贊助。Claude 和 Claude Code 是 Anthropic 的商標。

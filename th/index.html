ทำอะไรได้บ้าง

Usagette อยู่บนแถบเมนูของ Mac และแสดงว่าคุณใช้ขีดจำกัดการใช้งาน Claude ไปแล้วเท่าไร ได้แก่ ขีดจำกัดเซสชัน 5 ชั่วโมง ขีดจำกัดรายสัปดาห์ 7 วัน และนับถอยหลังสดๆ ถึงการรีเซ็ตแต่ละครั้ง เปิดหรือปิดส่วนต่างๆ ของการแสดงผลได้ตามต้องการ และเปิดแผงเพื่อดูภาพรวมทั้งหมด

  • อ่านจากสเตตัสไลน์ของ Claude Code Usagette ตั้งสคริปต์สเตตัสไลน์เล็กๆ ที่บันทึกตัวเลขที่ Claude Code รายงานอยู่แล้ว สเตตัสไลน์ของคุณเองยังทำงานได้ตามปกติ ตัวเลขรีเฟรชขณะที่คุณใช้ Claude Code และระหว่างเซสชันการนับถอยหลังก็เดินต่อไป
  • เสียงที่ดังขึ้นตามการใช้งาน เลือกว่าเสียงเริ่มที่ใดและห่างกันเท่าไร แต่ละขั้นแรงกว่าขั้นก่อนหนึ่งระดับ รวมห้าระดับ คุณจึงรู้ว่าใกล้ถึงขีดจำกัดแค่ไหนโดยไม่ต้องมอง และมีเสียงสำหรับเมื่อถึงขีดจำกัดและเมื่อรีเซ็ตด้วย
  • โปรไฟล์ ปกติ (ระฆังนุ่มๆ) พื้นฐาน (เสียงมาตรฐานของ macOS) อนิเมะ (ประกายแสงและบทพูด ตลกขึ้นอีกนิด) และกำหนดเอง (ไฟล์เสียงของคุณเอง) คุณยังนำเข้าไฟล์โปรไฟล์เสียงของคุณเองได้
  • เงียบเมื่อควรเงียบ ช่วงเวลาเงียบ สวิตช์ปิดเสียง และเงียบขณะที่ Mac ล็อกอยู่
  • คำสั่งลัดและเปิดตอนเข้าสู่ระบบ เหมือนแอปอื่นๆ ในตระกูลเดียวกัน

ต้องใช้ macOS 14 Sonoma ขึ้นไปและ Claude Code เร็วๆ นี้บน Mac App Store ขีดจำกัดการใช้งานแสดงโดย Claude Code สำหรับแพ็กเกจสมาชิกที่มีขีดจำกัดเหล่านี้

โปรไฟล์เสียงฟรี

เสียงเพิ่มเติมสำหรับ Usagette ดาวน์โหลดได้ฟรี แต่ละโปรไฟล์จะไต่ระดับไปตามทั้งห้าระดับ และมีเสียงของตัวเองสำหรับตอนถึงขีดจำกัดและตอนรีเซ็ต

  • ดาวน์โหลด8-Bit Adventure. เหรียญและพาวเวอร์อัป ตามด้วยเสียงบี๊บแจ้งข้อผิดพลาดและสัญญาณเตือนพลังชีวิตต่ำ เสียงร้องเกมโอเวอร์เมื่อถึงขีดจำกัด และเสียงแตรฟานแฟร์เมื่อรีเซ็ต เสียงโดย Juhani Junkala สาธารณสมบัติ (CC0)
  • ดาวน์โหลดArcade Announcer. ผู้ประกาศในเกม: ช่วงแรกประกาศอย่างสงบ เมื่อไต่ขึ้นก็เป็น “Hurry up!” และ “Look out!” แล้วเป็น “Game over” เมื่อถึงขีดจำกัด เสียงพูดโดย Kenney สาธารณสมบัติ (CC0)
  • ดาวน์โหลดMusic Box. ทำนองไขลานเล็ก ๆ ที่ค่อย ๆ ช้าลงและต่ำลงเมื่อใกล้ถึงขีดจำกัด เสียงต้นฉบับ สร้างขึ้นเพื่อ Usagette
  • ดาวน์โหลดRetro Console. เสียงบี๊บชิปทูนจากเครื่องเกม 8 บิตในจินตนาการ: พาวเวอร์อัป ไซเรนเตือน และทำนองเกมโอเวอร์ เสียงต้นฉบับ สร้างขึ้นเพื่อ Usagette
  • ดาวน์โหลดSinging Bowls. ช่วงแรกเป็นเสียงขันใบเดียวที่นุ่มนวล ยิ่งไต่ขึ้นยิ่งต่ำลงและถี่ขึ้น และเสียงฆ้องเมื่อถึงขีดจำกัด เสียงต้นฉบับ สร้างขึ้นเพื่อ Usagette
  • ดาวน์โหลดSonar Dive. โซนาร์เรือดำน้ำ: เสียงปิงเดี่ยว ๆ แล้วเร็วขึ้น แตรดำน้ำเมื่อถึงขีดจำกัด และเสียงฟองอากาศตอนลอยขึ้น เสียงต้นฉบับ สร้างขึ้นเพื่อ Usagette

หากต้องการเพิ่ม ให้เปิดการตั้งค่า › โปรไฟล์เสียงใน Usagette แล้วเลือกนำเข้า… หรือวางไฟล์ที่ดาวน์โหลดไว้ตรงนั้น หรือจะคลายซิปแล้วดับเบิลคลิกโปรไฟล์ก็ได้

ความเป็นส่วนตัวในย่อหน้าเดียว

Usagette ไม่เข้าถึงเครือข่าย ไม่มีบัญชี ไม่ติดตามผู้ใช้ และไม่มีสิ่งใดออกจาก Mac ของคุณ แอปอ่านไฟล์เดียวที่สคริปต์สเตตัสไลน์เขียนไว้ ในโฟลเดอร์ .claude ที่คุณอนุญาตให้ใช้ นโยบายความเป็นส่วนตัวฉบับเต็มกล่าวไว้เหมือนกันในรายละเอียดมากขึ้น

แอปอื่นๆ จากผู้พัฒนาคนเดียวกัน

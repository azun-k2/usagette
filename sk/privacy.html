Tento preklad slúži pre pohodlie; záväzné sú anglické zásady ochrany súkromia. Naposledy aktualizované 2. októbra 2026.

Stručne

Usagette nezhromažďuje údaje, nič neodosiela a nemá prístup k sieti. Nie je tu účet, analytika ani sledovanie.

Čo Usagette číta a zapisuje

Usagette pracuje s priečinkom, ktorý si vyberiete: priečinkom .claude aplikácie Claude Code vo vašom domovskom priečinku. macOS vás požiada o jeho výber raz, v bežnom paneli Otvoriť, a Usagette si voľbu zapamätá.

  • Číta jeden súbor, ktorý sama vytvorila, .claude/usagette/status.json, v ktorom sú čísla používania a časy resetov, ktoré Claude Code hlási svojmu stavovému riadku. Nečíta vaše konverzácie, projekty ani nič iné v priečinku.
  • Zapisuje iba vlastné súbory pre prepojenie v .claude/usagette a položku statusLine v .claude/settings.json, aby pripojila skript stavového riadka. Váš predošlý stavový riadok sa zachová a spúšťa ako predtým a pred prvou zmenou sa uloží záloha súboru nastavení.

Čo sa ukladá a kde

Vo vlastnom úložisku aplikácie na vašom Macu: vaše nastavenia, posledné videné čísla a váš výber priečinka. Odstránením aplikácie sa vymažú. Súbory stavového riadka zostanú v priečinku .claude, kým nestlačíte Odstrániť v Nastaveniach; obsahujú iba čísla používania.

Kam to ide

Nikam. Usagette nemá prístup k sieti. Nemá sieťové oprávnenie, takže jej samotný macOS nedovolí otvoriť spojenie. Nie je tu server a nič neopúšťa váš Mac.

Nezávislosť

Usagette je vytvorená nezávisle a nie je prepojená so spoločnosťou Anthropic, ňou schválená ani sponzorovaná. Claude a Claude Code sú ochranné známky spoločnosti Anthropic.

기능

Usagette는 Mac 메뉴 막대에 상주하며 Claude 사용량 한도를 얼마나 썼는지 보여 줍니다. 5시간 세션 한도, 7일 주간 한도, 각 초기화까지의 실시간 카운트다운입니다. 표시할 항목은 켜고 끌 수 있고, 패널을 열면 전체 상황을 볼 수 있습니다.

  • Claude Code의 상태 줄에서 읽습니다. Usagette는 Claude Code가 이미 보고하는 숫자를 저장하는 작은 상태 줄 스크립트를 설정합니다. 기존 상태 줄도 계속 작동합니다. 숫자는 Claude Code를 사용하는 동안 갱신되고, 세션 사이에는 카운트다운이 그대로 이어집니다.
  • 사용량에 따라 높아지는 소리. 소리가 시작되는 지점과 소리 사이 간격을 고르세요. 각 단계는 다섯 단계에 걸쳐 한 단계씩 강해지므로 보지 않고도 얼마나 가까워졌는지 알 수 있습니다. 한도에 도달했을 때와 초기화됐을 때의 소리도 있습니다.
  • 프로필. Normal(부드러운 차임), Basic(macOS 기본 사운드), Anime(반짝임과 보이스, 조금 더 엉뚱함), Custom(내 사운드 파일). 직접 만든 사운드 프로필 파일을 가져올 수도 있습니다.
  • 필요할 땐 조용히. 방해 금지 시간, 음소거 스위치, Mac이 잠겨 있는 동안의 무음.
  • 단축어와 로그인 시 열기도 패밀리의 다른 앱과 같습니다.

macOS 14 Sonoma 이상과 Claude Code가 필요합니다. Mac App Store에 곧 출시됩니다. 사용량 한도는 한도가 있는 구독 요금제에 대해 Claude Code가 표시합니다.

무료 사운드 프로필

Usagette용 사운드를 무료로 내려받을 수 있습니다. 각 프로필은 다섯 단계를 거치며 올라가고, 한도와 초기화를 위한 고유한 소리가 있습니다.

  • 다운로드8-Bit Adventure. 동전과 파워업, 이어서 오류음과 체력 저하 경보, 한도에서 게임 오버 비명, 초기화될 때 팡파르. 사운드: Juhani Junkala, 퍼블릭 도메인(CC0).
  • 다운로드Arcade Announcer. 게임 아나운서: 처음에는 차분한 안내, 올라갈수록 “Hurry up!”, “Look out!”, 한도에서 “Game over”. 음성: Kenney, 퍼블릭 도메인(CC0).
  • 다운로드Music Box. 태엽 감는 작은 멜로디가 한도가 가까워질수록 느리고 낮게 잦아듭니다. Usagette를 위해 만든 오리지널 사운드.
  • 다운로드Retro Console. 상상 속 8비트 게임기의 칩튠 효과음: 파워업, 경고 사이렌, 게임 오버 멜로디. Usagette를 위해 만든 오리지널 사운드.
  • 다운로드Singing Bowls. 처음에는 부드러운 그릇 소리 하나, 올라갈수록 낮고 촘촘해지며, 한도에서 징이 울립니다. Usagette를 위해 만든 오리지널 사운드.
  • 다운로드Sonar Dive. 잠수함 소나: 외로운 핑 소리, 이어서 더 빠른 핑, 한도에서 잠항 경보, 올라가는 동안 거품 소리. Usagette를 위해 만든 오리지널 사운드.

추가하려면 Usagette의 설정 › 사운드 프로필에서 가져오기…를 선택하거나 내려받은 파일을 그곳에 드롭하세요. 압축을 풀고 프로필을 더블클릭해도 됩니다.

개인정보 보호, 한 단락으로

Usagette에는 네트워크 접근, 계정, 추적이 없으며 어떤 것도 Mac 밖으로 나가지 않습니다. 허용한 .claude 폴더 안에서 상태 줄 스크립트가 작성하는 파일 하나만 읽습니다. 전체 개인정보 처리방침도 같은 내용을 더 자세히 설명합니다.
